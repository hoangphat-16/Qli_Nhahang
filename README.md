Dự án Quản lý Nhà hàng (MVC)
Hệ thống quản lý đặt món và vận hành nhà hàng theo mô hình MVC, hỗ trợ quản lý thực đơn trên nền tảng PHP.
Cách chạy dự án:
Mở Terminal tại thư mục gốc và chạy lệnh composer install
Mở file .env, kiểm tra và điều chỉnh các thông số kết nối Database (DB_NAME, DB_USER, DB_PASS) cho khớp với máy
Gõ lệnh php server.php (hoặc lphp -S localhost:8000 -t public) để khởi động ứng dụng.
